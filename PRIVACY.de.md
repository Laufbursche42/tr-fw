# Datenschutz

Kurz gesagt: diese Seite sammelt nichts. Es gibt keine Anmeldung, keine Cookies, keine Zählpixel, keine Statistik und keine Werbung.

## Deine Firmware-Datei

Die Datei, die du auswählst, wird **im Browser gelesen und dort verarbeitet**. Sie wird nicht hochgeladen, nicht zwischengespeichert und nicht an einen Server gesendet. Die gebaute Firmware entsteht ebenfalls auf deinem Gerät und landet als Download in deinem Dateisystem.

Du kannst das nachprüfen: schalte nach dem Laden der Seite die Netzwerkverbindung ab. Das Bauen funktioniert weiterhin.

Der Button **EEPROM prüfen** verbindet sich per Bluetooth direkt aus deinem Browser mit deinem eigenen Roller, an einen Server geht keiner der angezeigten Werte.

## Hosting

Die Seite liegt bei GitHub Pages. GitHub protokolliert Aufrufe seiner Server, dazu gehört üblicherweise die IP-Adresse, der Zeitpunkt und die abgerufene Adresse. Darauf haben wir keinen Einfluss und wir sehen diese Protokolle auch nicht.

Was GitHub damit macht, steht in der [GitHub Privacy Statement](https://docs.github.com/site-policy/privacy-policies/github-privacy-statement).

## Wenn du ein Ticket öffnest

Ein Ticket ist ein öffentlicher GitHub-Vorgang. Dein Benutzername, dein Text und alles, was du anhängst, sind damit öffentlich sichtbar. Häng nichts an, was du nicht veröffentlichen willst, insbesondere keine Daten, die dich oder dein Fahrzeug identifizieren.
